# Журнал изменений

Файл собирается из git-истории командой `sh scripts/changelog.sh`.
Раздел выбирается по типу коммита: `feat` → Новое, `fix` → Исправления,
`docs` → Документация; `refactor`, `test`, `chore`, `ci` не попадают.
